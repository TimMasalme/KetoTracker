# Contributing to KetoTrack

Thank you for your interest in KetoTrack!

## How you can contribute

Since KetoTrack is a proprietary project (see [LICENSE](LICENSE)), direct code contributions via pull requests are not accepted at this time.

However, you are very welcome to:

- **Report bugs** — open an [Issue](https://github.com/TimMasalme/KetoTrack/issues) with a clear description, steps to reproduce, and your platform (Windows / Android / browser)
- **Request features** — open an Issue with the label `enhancement` and describe what you'd like to see
- **Report security vulnerabilities** — please follow the [Security Policy](SECURITY.md) and do **not** open a public issue for security problems

## Bug report checklist

When filing a bug, please include:

- KetoTrack version (visible in Settings)
- Platform and OS version (e.g. Android 14, Windows 11)
- Steps to reproduce the issue
- What you expected to happen vs. what actually happened
- Any relevant error messages or screenshots

## Feature requests

Feature requests are welcome. Please check the existing issues first to avoid duplicates. Describe the use case clearly — the more context, the better.
