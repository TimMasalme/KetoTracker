# Code of Conduct

## Our Standards

Everyone interacting with the KetoTrack project — in issues, discussions, or any other space — is expected to:

- Be respectful and constructive
- Focus on the problem, not the person
- Accept that decisions about the project are at the sole discretion of the author
- Refrain from harassment, discrimination, or abusive language of any kind

## Unacceptable behaviour

- Personal attacks or insults
- Trolling or deliberately disruptive behaviour
- Spam or off-topic promotion
- Sharing others' private information without consent

## Enforcement

Violations may result in comments being removed or the user being blocked from the repository. The project author has final say on all moderation decisions.

## Contact

If you witness or experience unacceptable behaviour, contact the project author via GitHub.

---

*This Code of Conduct applies to all project spaces managed by Tim El Masalme.*
